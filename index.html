    How the count works

    Basic SRT timestamps are required. Cue numbers are optional. Line breaks become spaces; repeated whitespace is collapsed. Common b, i, u and font tags are removed, and common text entities are decoded once. Other markup remains text.

    Unicode grapheme clusters are counted where Intl.Segmenter is available; otherwise the counter uses Unicode code points. Spaces and punctuation count. Invalid timestamps, nonpositive durations and empty dialogue are reported separately.

    This examines timing and text length, not translation accuracy. Text stays in this demo; its code makes no network requests.
