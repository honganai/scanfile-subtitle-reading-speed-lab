# Subtitle reading-speed lab

An original, AI-assisted browser example for SRT cue authors and web-code learners. Open `index.html` with its CSS and JavaScript files alongside it. No build step or external dependency is required.

The calculator compares Unicode text counts with cue duration and a user-selected threshold. The synthetic example includes a crowded cue, CJK text, a joined emoji and an invalid duration. Common subtitle formatting tags and entities are handled; the UI explains the counting rules and browser fallback. User text is rendered with `textContent`.

Run the logic checks with Node.js 20 or later:

```sh
node reading-speed.test.cjs
```
